The site includes English and Spanish content, project media and a responsive interface. The public GitHub profile also provides [engineering case studies and contribution boundaries](https://github.com/Ahgarzon/Ahgarzon/blob/main/PROJECTS.md).

## Repository

The website is built with HTML, CSS and JavaScript, with media in `assets/`. GitHub Pages publishes it on the domain defined by `CNAME`.

To preview locally with Python installed:

```bash
python -m http.server 8000
```

Open `http://localhost:8000/?enfoque=perfil` for the professional journey, or `http://localhost:8000/?enfoque=negocio` for the business journey. No application build step is required for the main static page.
